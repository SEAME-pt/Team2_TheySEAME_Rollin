# Eletric Schemes Notes

## Color Table

Here's the cable color codes and their respective color, used in the eletric scheme

| Color Code | Color     |
| ---------- | --------- |
| BK         | Black     |
| BN         | Brown     |
| RD         | Red       |
| OG         | Orange    |
| YE         | Yellow    |
| GN         | Green     |
| BU         | Blue      |
| VT         | Violet    |
| GY         | Grey      |
| WH         | White     |
| PK         | Pink      |

## STM Jumper Position

The STM Jumper, **JP4** in the eltric scheme, should be in this positions

**If you want to connect the STM to a PC**, put the jumper **5V_USB_STLK**
**If you want to connect the STM to a 5V pin**, put the jumper **5V_VIN**
